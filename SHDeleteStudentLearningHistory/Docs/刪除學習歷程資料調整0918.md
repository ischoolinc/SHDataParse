## 3. Program.cs 傳入 SelectedSource 的調整

開啟表單時，將目前學生面板選取來源傳入 constructor：

```csharp
frmDelStudentLearningHistory fDLH =
    new frmDelStudentLearningHistory(
        K12.Presentation.NLDPanels.Student.SelectedSource
    );
```

仍保留 `SelectedSource.Count > 0` 才開啟表單的判斷，以及 `ShowDialog()` 呼叫方式不變。

## 4. 表單保存 Student IDs 的方式

* 新增欄位：`private List<string> _StudentIDs;`
* constructor 改為接收 `List<string> studentIDs`
* 以複製方式保存，避免後續 SelectedSource 變更影響表單：

```csharp
_StudentIDs = studentIDs == null
    ? new List<string>()
    : new List<string>(studentIDs);
```

後續刪除功能可統一使用 `_StudentIDs`。

## 5. SchoolYear 初始化方式

於 `InitSchoolYear()`：

1. 讀取 `K12.Data.School.DefaultSchoolYear`
2. `int.TryParse` 轉成整數
3. 清除 `cbxSchoolYear.Items`
4. 加入 `DefaultSchoolYear - 3` 至 `DefaultSchoolYear + 3`（共 7 項）
5. 以 `cbxSchoolYear.Text` 選取預設學年度

未寫死學年度數字。

## 6. Semester 初始化方式

於 `InitSemester()`：

* 選項僅 `"1"`、`"2"`
* 預設文字設為 `K12.Data.School.DefaultSemester`
* `DropDownStyle = ComboBoxStyle.DropDownList`，禁止自行輸入

## 7. ScoreType 固定選項

於 `InitScoreType()` 固定加入 10 種：

1. 學期成績(4.2)
2. 補修成績(4.3)
3. 轉學轉科成績(4.4)
4. 重修成績(5.2)
5. 重讀成績(5.3)
6. 學期成績(6.2)
7. 補考成績(6.3)
8. 轉學轉科成績(6.4)
9. 學期成績(預檢)(41.2)
10. 學期成績(預檢)(42.2)

預設 `SelectedIndex = 0`（學期成績(4.2)）。

## 8. ComboBox 限制輸入方式

* `cbxSemester.DropDownStyle = ComboBoxStyle.DropDownList`
* `cbxScoreType.DropDownStyle = ComboBoxStyle.DropDownList`

僅能從清單選擇，不可手動輸入其他值。

## 9. 初始化流程整理

於 `frmDelStudentLearningHistory_Load` 保留原本固定視窗大小：

```csharp
this.MinimumSize = this.MaximumSize = this.Size;
```

並集中呼叫：

```csharp
InitializeFormData();
  ├─ InitSchoolYear()
  ├─ InitSemester()
  └─ InitScoreType()
```
